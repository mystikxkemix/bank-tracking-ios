# AI Memory - Comptes (Bank tracking iOS)

## Setup
- SwiftUI + Observation (`@Observable`), iOS 17+, no third-party dependency. Project generated by `xcodegen` from `project.yml`: run `xcodegen generate` after adding/removing files, never edit the `.xcodeproj`.
- Bundle id `io.github.mystikxkemix.banktracking`, display name "Comptes". Automatic signing: select a team once in Xcode for a device.

## Contract
- The API contract lives in the web repo (`packages/shared/src/schemas`). `API/Models.swift` mirrors it by hand: when a schema changes there, update the Swift struct and `DecodingTests`.
- Space-scoped routes: `/api/spaces/:spaceId/<feature>`. Transactions come newest first, which the day grouping relies on.
- `/api/health` returns `{ ok, version }` since server 1.8 (shown in Réglages).

## Gotchas
- iOS 26 large titles disappear under a `safeAreaInset` header: the Budgets tab uses an inline title for that reason.
- `@Environment` is used in a plain `View` (`SpaceMenuButton`) placed inside `ToolbarItem`, not in a `ToolbarContent` struct.
- The demo seed of the web repo stops at the previous month: use `BT_MONTH` to screenshot a month with data.
- ATS: production must be HTTPS. `NSAllowsLocalNetworking` only covers dev addresses.
